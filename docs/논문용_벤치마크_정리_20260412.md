## 3. Table 3: Box IoU only vs EdgePPE-Net

- GT subset:
  - 프레임 수: 20
  - worker instance 수: 58
- 포함된 시나리오:
  - 정상 착용: 20
  - 인접 작업자 겹침: 17
  - 안전모만 미착용: 8
  - 조끼만 미착용: 13
- 아직 빠진 시나리오:
  - 보호장비를 손에 들고 있는 경우
  - 안전모/조끼 모두 미착용

| Method | Precision | Recall | F1 | FP Rate |
|---|---:|---:|---:|---:|
| Box IoU only | 0.8500 | 0.8095 | 0.8293 | 0.0811 |
| EdgePPE-Net | 1.0000 | 0.6667 | 0.8000 | 0.0000 |

해석:

- 현재 튜닝된 EdgePPE-Net은 이 subset에서 오탐을 완전히 제거하여 FP Rate를 0.0000으로 낮췄다.
- 반면 recall은 0.6667로 감소하여, 전체 F1은 Box IoU only보다 소폭 낮게 나타났다.
- 특히 `adjacent_overlap` 장면에서 Box IoU only는 FP 3건이 발생했으나, EdgePPE-Net은 해당 오탐을 제거하였다.

논문용 서술 예시:

> 현재 테스트 subset에서 Box IoU only 방식은 Precision 0.8500, Recall 0.8095, F1 0.8293, FP Rate 0.0811을 기록하였다. 반면 제안한 EdgePPE-Net은 Precision 1.0000, Recall 0.6667, F1 0.8000, FP Rate 0.0000을 기록하였다. 이는 조건부 자세 추정 기반 후처리가 인접 작업자 겹침 상황에서 오탐을 효과적으로 억제함을 보여준다. 다만 현재 보수적으로 조정된 임계값 설정으로 인해 recall은 일부 감소하였다.

## 5. 논문 반영 시 권장 포인트

1. 탐지 성능 표는 CPU / Coral USB / PCIe HAT 3개를 함께 제시하는 것이 좋다.
2. Table 3는 현재 결과만으로도 넣을 수 있지만, 아래 두 시나리오를 추가하면 더 설득력이 커진다.
   - 보호장비를 손에 들고 있는 장면
   - 안전모와 조끼가 모두 없는 장면
3. 현재 Table 3 수치는 오탐 억제에 강하게 맞춘 설정이라 FP는 크게 줄였지만 recall이 일부 낮아졌다. 따라서 본문에서는 "오탐 감소에 효과적"이라는 방향으로 해석하는 것이 적절하다.
